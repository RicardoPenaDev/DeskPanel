# Tarefa — Fase 4: Editor do painel

Referência: `PROJECT.md` §17 (Fase 4), §10.2-C.

## Feito

- `storage/pageSlots.ts`: helpers puros `pageSlots`/`applySlots` que convertem uma página (array esparso de `DashboardButton` com `position`) em slots densos de tamanho `columns*rows` e de volta — usados por reorganizar, adicionar e mover botões.
- `components/Icon.tsx`: 17 ícones SVG locais (sem dependência externa), chaves alinhadas com `configs/config.example.json`; fallback genérico para nome desconhecido. `components/DashboardButton.tsx` e `features/dashboard/DashboardScreen.tsx` passaram a renderizar o ícone de verdade em vez de só texto.
- `features/editor/ActionPicker.tsx`: lista de ações do catálogo autoritativo do Mac para escolher — nunca aceita um `actionId` digitado livremente.
- `features/editor/EditorScreen.tsx`: componente controlado (não guarda cópia própria do layout) com:
  - abas de página: criar (`+ Nova página`), excluir (bloqueado quando resta só 1), trocar de aba;
  - grade de slots: vazio → escolher ação; ocupado → abrir painel de edição;
  - painel de edição: trocar ação, nome (`labelOverride`), ícone (`iconOverride`), cor, toque prolongado (travado quando a ação já é perigosa — ver ADR-0005), mover para outra página (com erro se a página de destino estiver cheia), remover botão;
  - modo "Reorganizar botões": tocar para selecionar, tocar no destino para mover/trocar (ver ADR-0005 sobre a escolha em vez de drag-and-drop literal);
  - "Restaurar layout padrão" com confirmação antes de aplicar.
- `features/connection/useDeskPanelConnection.ts`: novos `updateLayout`/`resetLayoutToDefault` (deps injetáveis `saveLayout`/`resetLayout`), persistindo cada mutação do editor imediatamente.
- `storage/layoutStorage.ts`: validação mais estrita (checa forma de páginas/botões, não só `schemaVersion`) + backup automático (`deskpanel.layout.backup`, promovido só após gravação válida) — cadeia de fallback: principal válido → backup válido → padrão de fábrica.
- `App.tsx`: alterna entre painel e editor (`onOpenEditor`/`onClose`); `DashboardScreen` ganhou botão "Editar" no cabeçalho e toque prolongado em slot vazio como segunda forma de entrar no editor.

## Critérios de saída (PROJECT.md §17) — conferidos

- Layout sobrevive a reinício: toda mutação do editor chama `saveLayout` via `updateLayout` antes de atualizar o estado em memória (mesmo padrão de persistência imediata já usado no token/config de conexão).
- Config corrompida usa backup ou padrão sem travar: coberto por `layoutStorage.test.ts` (corrupção do JSON, `schemaVersion` incompatível, com e sem backup disponível).
- Editor nunca cria ação executável nova no Mac: `ActionPicker` só lista `actionsCatalog` (vindo do agente via `/actions`); não existe nenhum campo livre de `kind`/`parameters` no editor.
