# Tarefa — Fase 5: Instalação real

Referência: `PROJECT.md` §17 (Fase 5), §14.2, §14.3.

Importante: `PROJECT.md` §19.3 proíbe criar tag, publicar release, enviar ao
GitHub, instalar no Mac real ou executar ação real sem autorização explícita
do proprietário. Esta fase entrega os scripts, o LaunchAgent e a
documentação; a execução real (instalar no Mac de verdade, carregar o
LaunchAgent, compilar o APK com Gradle/Android SDK reais, parear com o Moto
G60 físico) depende dessa autorização e não foi feita.

## Feito

- `scripts/install-macos.sh`: verifica `uname -s == Darwin` (aborta em
  qualquer outro sistema); compila com `go build` ou usa `--binary
  <caminho>`; cria `~/Library/Application Support/DeskPanel/{bin,}` (`0700`)
  e `~/Library/Logs/DeskPanel/`; instala o binário (`0755`); cria
  `config.json` a partir de `configs/config.example.json` só se ausente
  (`--force` para sobrescrever); gera o LaunchAgent
  (`dev.ricardopena.deskpanel.agent.plist`) com caminhos resolvidos em tempo
  de instalação (sem usuário fixo hardcoded); carrega via `launchctl
  bootstrap gui/$(id -u)` (com `bootout` antes, idempotente); imprime
  `status`/`pair`/`doctor`. Flags: `--binary`, `--force`,
  `--skip-launchagent`, `--no-load`, `-h/--help`.
- `scripts/uninstall-macos.sh`: `launchctl bootout` + remove o `.plist` e o
  binário; preserva `config.json`/`devices.json`/`state.json`/logs por
  padrão; `--purge` remove tudo, com confirmação interativa a menos que
  `--yes`/`-y` também seja passado.
- `scripts/build-apk.sh`: `pnpm install` (só se necessário), `pnpm test`,
  `pnpm build`, `npx cap sync android`, `./gradlew assembleDebug` ou
  `assembleRelease`, imprime o caminho final do `.apk`. Flags: `--release`,
  `--web-only` (pula o Gradle), `--skip-install`, `--skip-tests`.
- `docs/INSTALL-MACOS.md` e `docs/INSTALL-ANDROID.md` reescritos com o fluxo
  real (instalar, verificar, desinstalar, reinstalar do zero, instalação no
  Moto G60 via ADB e manual). `README.md` ganhou seção "Instalação real"
  linkando os dois guias.
- ADR-0006 registrando as decisões de desenho dos scripts (não-destrutivo
  por padrão, `KeepAlive.SuccessfulExit=false` no LaunchAgent, `--web-only`
  para validar o pipeline sem SDK Android).

## Critérios de saída (PROJECT.md §17) — status

- "agente volta após logout/login": coberto pelo desenho do LaunchAgent
  (`RunAtLoad=true`, `KeepAlive.SuccessfulExit=false`) — **não validado**
  fisicamente (exige Mac real + logout/login real).
- "Moto G60 reconecta automaticamente": mecanismo já existe desde a Fase 3
  (`wsClient` com backoff) — **não validado** com o aparelho físico.
- "ações básicas funcionam no setup real": **pendente** — requer Mac real +
  agente instalado + celular pareado.
- "documentação permite reinstalação do zero": `docs/INSTALL-MACOS.md`
  documenta `uninstall-macos.sh --purge --yes` seguido de
  `install-macos.sh` — validado por leitura/revisão, não por execução real.

## Não feito nesta fase

- Instalação real no Mac do usuário (script não foi executado contra o
  sistema real, só validada a sintaxe e a guarda de plataforma).
- Carregamento real do LaunchAgent via `launchctl`.
- Compilação real do APK via Gradle/Android SDK (só o caminho `--web-only`
  foi executado de ponta a ponta neste ambiente).
- Pareamento e teste físico no Moto G60.
- Tudo que já estava listado como pendente nas fases anteriores
  (Configurações, `keystroke`/`screen_lock`/`display_sleep` no executor,
  compilação nativa Android).

  — todos os pacotes OK; `go build -o bin/deskpanel-agent
  ./cmd/deskpanel-agent` OK.
- `apps/android-panel`: `vitest run` — 94 testes / 18 arquivos passando
  (sem mudança de código de produção nesta fase); `eslint .` limpo;
  `prettier --check .` limpo; `tsc -b` limpo; `pnpm build` OK.
- `scripts/install-macos.sh` / `scripts/uninstall-macos.sh`: `bash -n`

  já que este não é um Mac).

  ponta neste ambiente — testes, build web e `cap sync android` completos
  com sucesso.
