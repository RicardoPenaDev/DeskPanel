# Tarefa — Fase 3: Painel Android funcional

Referência: `PROJECT.md` §17 (Fase 3), §10.

## Feito

- `src/protocol/httpClient.ts`: `/health`, `/version`, `/pair`, `/actions`, `/state`, com timeout, mapeamento de erro para códigos do protocolo e nenhum vazamento de exceção crua.
- `src/protocol/wsClient.ts`: `auth.hello`/`auth.accepted`, `action.execute`/`started`/`result` por `requestId`, `ping`→`pong`, reconexão com backoff 1s/2s/4s/8s/15s (+jitter), timeout de autenticação.
- Storage não secreto (`@capacitor/preferences`): `storage/connectionConfig.ts` (deviceId estável, IP/porta/nome) e `storage/layoutStorage.ts` + `storage/defaultLayout.ts` (layout padrão de 2 páginas × 8 botões, §10.4).
- Token no Android Keystore: `services/secureTokenStorage.ts` + plugin Capacitor local `SecureTokenStoragePlugin.java` (`EncryptedSharedPreferences`) — ver ADR-0004. Fallback web só para dev, em memória, não seguro por design.
- `features/connection/useDeskPanelConnection.ts`: hook central que liga storage + HTTP + WS, com dependências injetáveis (testável sem mockar módulos).
- UI: `components/StatusBadge`, `components/PageIndicator`, `components/DashboardButton` (5 estados + toque prolongado de 600ms para ações perigosas), `features/pairing/PairingScreen`, `features/dashboard/DashboardScreen` (grade 4×2, troca de página por gesto). `App.tsx` roteia entre pareamento e painel.
- `AndroidManifest.xml`: `android:screenOrientation="landscape"`. `MainActivity.java`: registra o plugin de token e liga `FLAG_KEEP_SCREEN_ON`.
- `configs/config.example.json` ampliado de 5 para as 16 ações do layout padrão (§10.4), validado subindo o agente real (`serve` → "16 ações registradas").

## Critérios de saída (PROJECT.md §17) — conferidos

- Painel executa ações usando o agente de teste: coberto pelos testes de `useDeskPanelConnection`/`DashboardScreen` com `WsClient`/`executeAction` injetados (equivalente ao `FakeExecutor` do lado Go); não houve execução real de ação em nenhum teste.
- Nenhuma informação secreta aparece em log: token nunca passa por `console.log`/Preferences/URL — testes dedicados garantem isso em `httpClient`, `connectionConfig` e `PairingScreen`.
- APK de debug: **não gerado nesta fase** — sem Android SDK/Gradle neste ambiente (ver limitação abaixo). Fica para a Fase 5, com Gradle real no Mac do usuário.
